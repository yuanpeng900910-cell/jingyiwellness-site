## 买前必看

### Q：京颐养方是什么品牌？
A：京颐养方是合肥京东方医院主动健康业务下的健康产品与服务品牌。
品牌围绕药食同源、草本生活与健康礼赠场景，提供更日常的东方轻养方案。

标签：品牌 / 买前必看

### Q：京颐养方做的是什么业务？
A：不是单一卖货。
品牌在做产品体系、企业健康场景、线下体验和礼赠方案，强调可持续的日常健康管理。

标签：品牌 / 买前必看

### Q：京颐养方和普通养生品牌有什么区别？
A：核心差异是有医院场景基础、有中医科和健康管理资源，并在真实企业和社区场景落地。
同时强调合规表达，不把产品包装成“治病神器”。

标签：品牌 / 买前必看 / 注意事项

### Q：京颐养方的品牌主张是什么？
A：统一表达可用：“京医古法，颐养东方。”
茶饮场景可补充：“古方有味，四时有养。”
体质茶可补充：“一人一方，辨体调养。”

标签：品牌 / 买前必看

### Q：京颐养方有哪些产品体系？
A：覆盖药食养方、生活养方、节气养生、定制礼赠、健康场景共建五大体系。
销售时建议先问客户场景，再推荐产品组合。

标签：品牌 / 买前必看

### Q：京颐养方产品是不是药品？
A：不是药品，不替代药物或医疗服务。
定位是日常草本轻养和健康生活方式产品。

标签：合规 / 买前必看 / 注意事项

### Q：不知道怎么选产品时怎么做？
A：先问场景（自饮/送礼/企业福利/会议茶歇）。
再问人群（女性日常、加班人群、秋冬暖饮、商务客户等）。
最后按预算和交付周期给出2-3个组合。

标签：茶饮 / 买前必看 / 送礼团购

## 茶饮产品

### Q：这四款茶和普通花茶有什么区别？
A：它不是单一花茶或单一茶叶，而是围绕不同生活状态做草本复配。
一罐一泡、便携即饮，适合办公室、下午茶、出差和年轻化轻养场景。

标签：茶饮 / 茶饮产品

### Q：一罐可以喝多久 / 一罐可以泡几次？
A：建议一罐作为当天饮用量，可反复续水饮用，一般一罐可以喝一天。
味道变淡后即可更换，不建议隔夜饮用。

标签：茶饮 / 茶饮产品

### Q：怎么冲泡 / 需要煮吗？
A：建议使用沸水煮泡或焖泡5分钟以上，让草本、果干、根茎类原料的香气和风味充分释放。
办公室或外出场景如不方便煮，也可以用沸水长时间焖泡后饮用。

标签：茶饮 / 茶饮产品

### Q：为什么包装上只有一个大字？
A：这是系列视觉识别语言。
“颜”代表红颜茶，“湿”代表轻湿茶，“气”代表元气茶，“熬”代表熬夜茶。

标签：品牌 / 茶饮产品

### Q：第一次喝推荐什么组合？
A：可推荐“元气清润组合”：红颜茶+轻湿茶。

A：不建议随意混泡。

## 草本生活

### Q：一定要枕着睡吗？
A：不一定。
也可放床头、颈侧、沙发旁或办公午休区作为草本伴眠使用。

标签：香养 / 草本生活

### Q：为什么有草本味？
A：因为内部填充草本合香珠，本身会有植物气味，不是香精味。
首次使用可先通风散味再逐步适应。

标签：售后 / 草本生活 / 注意事项

### Q：能改善鼻敏感或睡眠吗？
A：建议表达：可作为睡眠环境和鼻部舒适感的草本陪伴产品。
但不能替代药物或医疗治疗。

标签：合规 / 草本生活 / 注意事项

### Q：哪些人慎用？
A：孕妇、儿童、G6PD缺乏症人群、对草本气味敏感者慎用。
如有不适应停止使用并保持通风。

标签：禁忌 / 草本生活 / 注意事项

### Q：怎么保养？
A：枕套可清洗；内胆建议每周晾晒一次；内胆不可水洗；
避免潮湿、高温和暴晒。

标签：售后 / 草本生活 / 注意事项

### Q：香味会不会很浓？
A：香气偏温和、内敛，不是香水式强扩散。
更适合近距离闻香与安静氛围。

标签：香养 / 草本生活

### Q：可以盘玩吗？
A：可以轻度盘玩。
建议净手后短时盘玩，避免长时间大力揉搓。

标签：售后 / 草本生活 / 注意事项

### Q：能见水吗？
A：不建议见水。
洗手、洗澡、运动出汗时建议取下，避免受潮变形。

标签：禁忌 / 草本生活 / 注意事项

### Q：怎么保存？
A：长期不佩戴时，放入养香盒或密封袋，置于阴凉干燥处。
避免接触香水、精油和化学品。

标签：售后 / 草本生活 / 注意事项

### Q：能生发、治白发吗？
A：不能这样承诺。
应表达为日常头皮护理与梳理按摩体验，不是治疗产品。

标签：合规 / 草本生活 / 注意事项

### Q：适合什么人？
A：适合熬夜、压力大、头皮紧绷、久坐办公及喜欢草本香养的人群。
也适合作为礼物与企业伴手礼。

标签：香养 / 草本生活 / 送礼团购

### Q：怎么使用？
A：建议头发清洁干爽时使用，顺着头皮轻柔梳理。
每次几分钟即可，不要用力刮擦。

标签：售后 / 草本生活 / 注意事项

### Q：使用时要注意什么？
A：忌水、忌油、避汗。
湿发和使用精油时不要用香梳，避免摔打和长期潮湿。

标签：禁忌 / 草本生活 / 注意事项

### Q：怎么保养？
A：使用后用干净软布轻擦，阴凉干燥保存。
长时间不用时放回包装盒，避免受潮暴晒。

标签：售后 / 草本生活 / 注意事项
